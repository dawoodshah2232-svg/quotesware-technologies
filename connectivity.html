LIVE, DELAYED, STALE, CLOSED and OFFLINE should mean something.

A trading terminal should never make a stale price look live. QuotesWare uses explicit connection-state concepts so client UI, charts and broker tools can all react correctly.

  • Out-of-order tick protection

  • Primary/fallback provider health monitoring
