API principles

Stable contracts before clever integrations.

Versioned resources

Breaking changes belong in explicit API versions, not silent production updates.

Idempotency

High-risk financial actions must be safe to retry and produce explicit outcomes.

Permission scope

API credentials should inherit broker, tenant, role and action-level boundaries.

Observable failure

Error codes, request IDs, logs and audit events should make integration failures diagnosable.
